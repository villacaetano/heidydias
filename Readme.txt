# Heidy Q Dias – Personal Portfolio Website

Professional portfolio website of **Heidy Q Dias**, Marine Biologist specialising in deep-sea biotope classification, seabed mapping, benthic ecology and ecological quality assessment.

Built with the **SnapFolio** Bootstrap template (by BootstrapMade) and fully personalised.

---

## Live Preview

Open `index.html` in any modern browser.

---

## Features

- Responsive design (mobile, tablet & desktop)
- Dark ocean-themed colour scheme
- Hero section with typed text animation
- About section with profile & stats
- Skills & Expertise section
- Full Resume / CV section
- Research & Publications portfolio (linked to paper details page)
- Contact form (ready for backend integration)
- Smooth scrolling & AOS animations

## How to Edit Content

### 1. Personal Information
Edit `index.html`:
- Name, title, description → Hero section
- About text & stats
- Resume experience & education
- Contact details

### 2. Publications
- Main paper details → `portfolio-details.html`
- Portfolio grid → section `#portfolio` in `index.html`

### 3. Colours
Open `assets/css/main.css` and edit the CSS variables at the top:

```css
:root {
  --background-color: #0f172a;
  --accent-color: #22d3ee;
  /* etc. */
}
